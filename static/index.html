Analog dial (rotating pointer): Each entry covers one circular dial whose arrow rotates to point at a number 0–9. Draw the selection around the full dial circle. Set color to red, green, or blue to match the pointer color. Add one entry per decimal dial, ordered from most-significant (leftmost) to least-significant (rightmost) digit. Adjust binaryThreshold (in postprocessing → analog) if the pointer is not detected. Lower the value if the pointer color is faint. If your pointer is mostly dark and color detection fails, enable postprocessing.analog.decolor and test again.
